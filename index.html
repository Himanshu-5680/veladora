What runs on your computer

The checks are plain JavaScript, with tests. They work even when the model is off. Gemma 3 270M runs in a browser worker when WebGPU is available. The weights download once from Hugging Face and stay in this browser.

A closed API would need the folder uploaded before it could explain it. That folder may contain the secret.

What the small model may do

Temperature stays at 0.6, because small models repeat themselves when it is higher. The prompt is a short list with secrets hidden, not the whole folder. If the reply repeats, you see the written summary instead.

There is no cross-origin isolation header. That header would speed a CPU backup and would also block the download. WebGPU is the fast path. SmolLM2 135M is the backup model for computers without WebGPU.
